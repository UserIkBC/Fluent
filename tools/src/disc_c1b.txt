# Hueco suelto C1 · lote B (gramática avanzada y conectores). Distractores reales y plausibles.
C1 ## Had the committee been more transparent, the scandal ___ have been avoided. ## might|would be|will|had ## Tercer condicional invertido: «had... been» pide «might/would have been avoided». // «Would be have» no es gramatical. // «Will have» no encaja con una condición irreal en pasado. // «Had have» no es correcto como verbo principal aquí. ## had the committee been=si el comité hubiera sido
C1 ## ___ in the 1990s, the firm has since expanded into twelve countries. ## Founded|Having found|To found|Being found ## Participio pasivo: «Founded in the 1990s» (la empresa fue fundada). // «Having found» es activa y exigiría un objeto. // «To found» es infinitivo y no encaja. // «Being found» significa que alguien la encuentra. ## founded in=fundada en
C1 ## Not until the contract had been signed ___ the full extent of the debt. ## did they realise|they realised|they did realise|realised they ## Tras «Not until» al inicio, el verbo principal se invierte: «did they realise». // Sin inversión es incorrecto. // «They did realise» no invierte el orden. // «Realised they» invierte sin auxiliar. ## not until... did they=no fue hasta... cuando
C1 ## It was the lack of funding ___ forced the project to close. ## that|what|who|which of ## Frase hendida: «It was X that...». // «What» no se usa en hendidas con «it was». // «Who» es para personas. // «Which of» no completa la frase. ## it was... that=fue... lo que
C1 ## What the committee needs ___ a clear timetable for the reforms. ## is|are|has|being ## «What the committee needs is...» con verbo en singular. // «Are» exigiría plural tras «what». // «Has» no encaja con el sujeto. // «Being» no es un verbo conjugado. ## what X needs is=lo que X necesita es
C1 ## The report, ___ was published last week, has caused a stir. ## which|that|what|who ## Tras coma se usa «which» en una subordinada explicativa. // «That» no puede ir tras coma en una explicativa. // «What» no introduce relativas así. // «Who» es para personas. ## non-defining relative=relativa explicativa
C1 ## The two directors, both of ___ had resigned, were interviewed by the press. ## whom|who|which|them ## Tras preposición para personas: «both of whom». // «Who» no se usa tras «of». // «Which» es para cosas. // «Them» no actúa como relativo. ## both of whom=ambos, los cuales
C1 ## I'd have signed the agreement if I ___ the risks. ## had understood|understood|would understand|have understood ## Tercer condicional: «if I had understood». // «Understood» sería segundo condicional. // «Would understand» no va en la cláusula con «if». // «Have understood» no es correcto tras «if». ## third conditional=tercer condicional
C1 ## If she ___ harder at school, she might be a doctor now. ## had worked|worked|would have worked|has worked ## Condicional mixto: «had worked» (pasado) con resultado en presente. // «Worked» no se refiere al pasado irreal. // «Would have worked» no va tras «if». // «Has worked» no es correcto. ## mixed conditional=condicional mixto
C1 ## He behaves as ___ he owned the place. ## if|though of|like of|than ## «As if» introduce una comparación hipotética. // «Though of» no existe. // «Like of» no existe. // «Than» no introduce esta estructura. ## as if=como si
C1 ## ___ being tired, she kept working until midnight. ## In spite of|Although|However|Even though of ## «In spite of» + -ing. // «Although» necesita sujeto y verbo. // «However» es un conector independiente. // «Even though of» no existe. ## in spite of + -ing=a pesar de
C1 ## The project was completed on time, ___ the unexpected delays. ## despite|although|however|whereas ## «Despite» va seguido de sustantivo. // «Although» exige oración con verbo. // «However» no une así. // «Whereas» expresa contraste entre dos cosas. ## despite=a pesar de
C1 ## Prices have risen sharply, ___ wages have remained flat. ## whereas|despite|owing to|so that ## «Whereas» expresa contraste. // «Despite» va con sustantivo. // «Owing to» expresa causa. // «So that» expresa finalidad. ## whereas=mientras que
C1 ## The company cut jobs ___ to reduce costs. ## in order|so as of|as to|for ## «In order to» expresa finalidad. // «So as of» no existe. // «As to» no es la estructura. // «For» no va seguido de infinitivo. ## in order to=para
C1 ## She left early ___ she could catch the last train. ## so that|in order|owing to|despite ## «So that» + oración expresa finalidad. // «In order» necesita «to» o «that». // «Owing to» es causa y va con sustantivo. // «Despite» no introduce oraciones. ## so that=para que
C1 ## ___ his lack of experience, he was offered the job. ## Notwithstanding|Whereas|Provided|Unless ## «Notwithstanding» (formal) significa a pesar de y va con sustantivo. // «Whereas» contrasta cláusulas. // «Provided» necesita «that». // «Unless» necesita una oración. ## notwithstanding=a pesar de
C1 ## You may use the equipment ___ you return it in good condition. ## provided that|despite that|owing that|as to ## «Provided that» significa siempre que. // «Despite that» no es la estructura. // «Owing that» no existe. // «As to» no expresa condición. ## provided that=siempre que
C1 ## ___ to his colleagues, he was always very polite. ## Contrary|Opposed|Unlike|Despite ## «Contrary to» significa al contrario de, contra lo que cabría pensar. // «Opposed» exige «to» pero cambia el sentido. // «Unlike to» no se dice. // «Despite to» no existe. ## contrary to=al contrario de
C1 ## The negotiations are ___ to continue next week. ## expected|waiting|hoped|thought of ## «Be expected to» es se espera que. // «Waiting to» no encaja con el sujeto. // «Hoped to» no sirve en pasiva así. // «Thought of» no lleva «to». ## be expected to=se espera que
C1 ## She regrets ___ him the truth when she had the chance. ## not telling|not to tell|not having told to|to not tell ## «Regret not telling» es lamentar no haber dicho. // «Not to tell» se usa para dar malas noticias. // «Not having told to» no es correcto. // «To not tell» no es natural. ## regret + -ing=lamentar haber
C1 ## I remember ___ the door, so it can't have been me who left it open. ## locking|to lock|lock|having locked up ## «Remember + -ing» es recordar haber hecho algo. // «Remember to lock» sería acordarse de hacerlo. // «Lock» no sigue a «remember». // «Having locked up» cambia el sentido. ## remember + -ing=recordar haber hecho
C1 ## The manager made it clear that he ___ no excuses. ## would accept|accepts|is accepted|accepting ## En estilo indirecto: «would accept». // «Accepts» no hace la concordancia temporal. // «Is accepted» es pasiva. // «Accepting» no es verbo conjugado. ## reported speech=estilo indirecto
C1 ## She asked me ___ I had finished the report. ## whether|that|what|which ## «Ask whether» introduce una pregunta indirecta sí o no. // «That» no introduce preguntas. // «What» pediría un dato. // «Which» pide elegir entre opciones. ## ask whether=preguntar si
C1 ## The security guard told us ___ the building before six. ## to leave|leave|we leave|that leave ## «Tell someone to do something» es ordenar que alguien haga algo. // «Leave» sin «to» no es correcto. // «We leave» no sigue a «told us». // «That leave» no es gramatical. ## tell somebody to=decirle a alguien que
C1 ## I'd prefer ___ to the conference rather than stay in the office. ## to go|go|going|that I go ## «Prefer to do» o «prefer doing»; con «rather than» y un solo sujeto, «to go». // «Go» sin «to» va con «would rather». // «Going» no sigue a «I'd prefer» con «rather than stay». // «That I go» es poco natural. ## would prefer to go=preferiría ir
C1 ## He is believed ___ the country last month. ## to have left|to leave|leaving|to be leaving ## Infinitivo perfecto: «to have left» para una acción pasada. // «To leave» sería presente o futuro. // «Leaving» no se usa así. // «To be leaving» indica algo en curso. ## believed to have left=se cree que se marchó
C1 ## There seems ___ a misunderstanding about the terms of the contract. ## to be|being|to have|be ## «There seems to be» es parece que hay. // «Being» no es correcto. // «To have» exige un objeto. // «Be» sin «to» no es correcto. ## there seems to be=parece que hay
C1 ## ___ the work, we went out for a meal. ## Having finished|Finishing|To finish|Finished of ## «Having finished» expresa una acción anterior con el mismo sujeto. // «Finishing» sugiere simultaneidad. // «To finish» expresa finalidad. // «Finished of» no es correcto. ## having finished=una vez terminado
C1 ## The lawyer, ___ by the verdict, decided to appeal. ## dissatisfied|dissatisfying|dissatisfy|dissatisfaction ## «Dissatisfied» es el adjetivo/participio pasivo: descontento. // «Dissatisfying» describiría lo que produce descontento. // «Dissatisfy» es verbo. // «Dissatisfaction» es sustantivo. ## dissatisfied=descontento
C1 ## I wasn't aware of him ___ the meeting. ## attending|to attend|attended|for attending ## «Aware of someone + -ing». // «To attend» no sigue a «aware of». // «Attended» no es correcto. // «For attending» no encaja. ## aware of him attending=consciente de que asistía
C1 ## There is no ___ in arguing with him; he never listens. ## point|use of|good for|reason of ## «There is no point in + -ing». // «No use of» no es correcto, se dice «no use». // «No good for» cambia el sentido. // «No reason of» no es correcto. ## there is no point in=no tiene sentido
C1 ## They have been ___ for the past two hours without reaching an agreement. ## negotiating|negotiated|to negotiate|negotiate ## Presente perfecto continuo: «have been negotiating». // «Negotiated» exige «have» sin «been». // «To negotiate» no sigue a «been». // «Negotiate» no sigue a «been». ## present perfect continuous=presente perfecto continuo
C1 ## By next summer, she ___ her degree. ## will have completed|will complete|completes|is completing ## Futuro perfecto: «will have completed» con «by next summer». // «Will complete» indica un momento futuro, no una acción acabada antes. // «Completes» es presente. // «Is completing» es acción en curso. ## future perfect=futuro perfecto
C1 ## This time next week, I ___ on a beach in Mallorca. ## will be lying|will lie|am lying|have lain ## Futuro continuo: acción en curso en un momento futuro. // «Will lie» es una acción puntual. // «Am lying» es presente. // «Have lain» es presente perfecto. ## future continuous=futuro continuo
C1 ## The suspect ___ to have been seen near the scene of the crime. ## is alleged|alleges|has alleged|is alleging ## «Be alleged to have» es se alega que. // «Alleges» es activa y falta sujeto. // «Has alleged» exige objeto. // «Is alleging» no encaja con «to have been seen». ## is alleged to=se alega que
C1 ## The company would rather ___ its profits than lose its reputation. ## sacrifice|sacrificing|to sacrifice|sacrificed ## «Would rather» + infinitivo sin «to». // «Sacrificing» no sigue a «would rather». // «To sacrifice» lleva «to» innecesario. // «Sacrificed» es pasado y cambia el sentido. ## would rather + infinitive=preferir
C1 ## No matter ___ hard she tried, she couldn't open the safe. ## how|what|which|so ## «No matter how + adjetivo/adverbio». // «What» pediría un sustantivo. // «Which» exigiría elegir entre opciones. // «So» no completa «no matter». ## no matter how=por mucho que
C1 ## We insisted that the contract ___ amended before signing. ## be|is|was|being ## Subjuntivo tras «insist that»: «be amended». // «Is» es indicativo. // «Was» es pasado indicativo. // «Being» no es verbo conjugado. ## insist that + subjunctive=insistir en que
C1 ## The directors demanded that the accounts ___ reviewed by an independent firm. ## be|were being|will be|are ## Subjuntivo tras «demand that». // «Were being» es pasado continuo. // «Will be» es futuro indicativo. // «Are» es indicativo. ## demand that + subjunctive=exigir que
C1 ## Were it not for the generous donation, the museum ___ closed. ## would have|will have|had|has ## Tercera condicional invertida: «Were it not for... would have closed». // «Will have» no va con condicional irreal. // «Had» sin participio no es correcto. // «Has» no es correcto. ## were it not for=si no fuera por
C1 ## The more companies invest in training, ___ productive their staff become. ## the more|more|most|the most ## «The more... the more». // Falta «the». // «Most» es superlativo. // «The most» es superlativo. ## the more... the more=cuanto más... más
C1 ## ___ you need any further information, please do not hesitate to contact us. ## Should|Would|Might|Must ## «Should you need» equivale a «if you need» en registro formal. // «Would you need» cambia el sentido. // «Might you need» es poco natural. // «Must you need» no es correcto. ## should you need=si necesitara
C1 ## I suggest we ___ the meeting until all the data is available. ## postpone|to postpone|postponing of|will postpone ## «Suggest we + infinitivo sin to» (subjuntivo). // «To postpone» no va tras «suggest we». // «Postponing of» no es correcto. // «Will postpone» no encaja con «suggest we». ## suggest we do=sugiero que hagamos
C1 ## She is ___ the most talented lawyer I have ever worked with. ## by far|by long|far away|more than ## «By far» refuerza un superlativo. // «By long» no existe. // «Far away» indica distancia. // «More than» no refuerza un superlativo. ## by far the=con diferencia el
C1 ## He was ___ responsible for the delay, since he had lost the documents. ## partly|part|partial|parted ## «Partly» es adverbio: en parte. // «Part» no es adverbio. // «Partial» es adjetivo. // «Parted» es participio de «part». ## partly=en parte
C1 ## It is hard to ___ what the consequences of the decision will be. ## foresee|forecast|predicate|preview ## «Foresee» es prever lo que va a ocurrir. // «Forecast» se usa para datos o el tiempo. // «Predicate» es basar algo en algo. // «Preview» es ver algo antes de su estreno. ## foresee=prever
C1 ## The new rules apply ___ all employees, regardless of their position. ## to|for|on|at ## «Apply to» es ser de aplicación a. // «Apply for» es solicitar. // «Apply on» no se usa así. // «Apply at» no se usa así. ## apply to=ser de aplicación a
C1 ## The company is not ___ for any damage caused by misuse. ## liable|likely|apt|unlikely ## «Liable for» es responsable de. // «Likely» es probable. // «Apt» es propenso. // «Unlikely» es improbable. ## liable for=responsable de
C1 ## We are ___ to announce that the merger has been completed. ## pleased|pleasing|pleasure|pleasant ## «Be pleased to» es tener el gusto de. // «Pleasing» describe lo que agrada. // «Pleasure» es sustantivo. // «Pleasant» describe algo agradable. ## be pleased to=tener el gusto de
C1 ## She succeeded ___ persuading the board to change its mind. ## in|at|on|with ## «Succeed in + -ing». // «Succeed at» se usa con tareas. // «Succeed on» no existe. // «Succeed with» no encaja aquí. ## succeed in=conseguir
C1 ## The government is committed ___ reducing unemployment. ## to|for|with|in ## «Be committed to + -ing». // «Committed for» no se usa. // «Committed with» no se usa. // «Committed in» no se usa. ## be committed to=estar comprometido con
C1 ## The two sides are close ___ reaching an agreement. ## to|on|at|with ## «Be close to + -ing». // «Close on» no se usa así. // «Close at» no se usa así. // «Close with» no se usa así. ## be close to=estar cerca de
C1 ## He apologised ___ the delay and promised it wouldn't happen again. ## for|of|about on|to ## «Apologise for» es disculparse por. // «Apologise of» no existe. // «About on» no existe. // «Apologise to» es disculparse ante alguien. ## apologise for=disculparse por
C1 ## The proposal is unlikely ___ approved without amendments. ## to be|being|to have|be ## «Be unlikely to be approved» es poco probable que se apruebe. // «Being» no es correcto. // «To have» exigiría participio con «been». // «Be» sin «to» no es correcto. ## be unlikely to=es poco probable que
C1 ## The workers went on strike ___ better pay and conditions. ## for|to|about|against ## «Strike for» es por. // «Strike to» no se usa. // «About» no es natural. // «Against» sería contra algo. ## strike for=hacer huelga por
C1 ## She holds a degree ___ law from the University of Valencia. ## in|of|on|at ## «A degree in» una disciplina. // «Degree of» no se usa con la materia. // «Degree on» no existe. // «Degree at» se usa con la universidad. ## degree in=título en
C1 ## He has a great ___ of respect for his opponents. ## deal|number|amount of|quantity ## «A great deal of» + incontable. // «Number» es para contables. // «Amount of» no lleva «of» detrás de «great». // «Quantity» no es natural con «respect». ## a great deal of=una gran cantidad de
C1 ## The new CEO takes ___ in a difficult period for the company. ## over|up|on|in ## «Take over» es asumir el mando. // «Take up» es empezar una actividad. // «Take on» es asumir una tarea. // «Take in» es absorber o engañar. ## take over=asumir el mando
C1 ## The lawyer ___ out several flaws in the prosecution's case. ## pointed|brought|turned|put ## «Point out» es señalar. // «Bring out» es sacar a la luz. // «Turn out» es resultar. // «Put out» es apagar. ## point out=señalar
C1 ## I'm afraid we have ___ out of the original stock. ## run|put|kept|gone ## «Run out of» es quedarse sin. // «Put out of» no se usa así. // «Keep out of» es mantenerse alejado. // «Go out of» no se usa así. ## run out of=quedarse sin
C1 ## The lawyers are trying to ___ up with a compromise. ## come|go|make|put ## «Come up with» es idear. // «Go up with» no existe. // «Make up with» es reconciliarse. // «Put up with» es tolerar. ## come up with=idear
C1 ## I can't ___ up with this noise any longer. ## put|come|keep|make ## «Put up with» es tolerar. // «Come up with» es idear. // «Keep up with» es seguir el ritmo. // «Make up with» es reconciliarse. ## put up with=tolerar
C1 ## We must ___ up with the latest developments in the sector. ## keep|put|come|catch ## «Keep up with» es mantenerse al día. // «Put up with» es tolerar. // «Come up with» es idear. // «Catch up with» es alcanzar a alguien. ## keep up with=mantenerse al día
C1 ## The deal fell ___ at the last minute because of a disagreement over the price. ## through|over|off|back ## «Fall through» es fracasar un acuerdo. // «Fall over» es caerse. // «Fall off» es disminuir o caerse de algo. // «Fall back» es retroceder. ## fall through=fracasar
C1 ## She decided to ___ on her promise and stay in Valencia after all. ## go back|follow through|fall back|turn back ## «Go back on a promise» es romper lo prometido, que encaja con «after all». // «Follow through on» es cumplir lo prometido, lo contrario. // «Fall back on» es recurrir a algo. // «Turn back on» no es la estructura. ## go back on=incumplir (una promesa)
C1 ## The negotiations are likely to ___ on for several more weeks. ## drag|drift|trail|spread ## «Drag on» es alargarse tediosamente. // «Drift on» no se usa así. // «Trail on» no se usa así. // «Spread on» no se usa así. ## drag on=alargarse
